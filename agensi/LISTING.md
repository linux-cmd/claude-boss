## Description

CLAUDE BOSS Workflow is a free, instruction-based skill for developers using Claude Code and compatible AI assistants. It gives your agent a repeatable method to assess a task, recommend an Economy/Balanced/Quality profile, select only relevant available skills and tools, and verify outcomes.

This package is **not** the full CLAUDE BOSS CLI and does **not** install or configure software by itself. For optional CLI commands, use the official GitHub repository. A skill suggestion is not evidence that a tool actually ran.

### Included
- Model-profile decision guidance, with compatibility caveats
- Task-aware routing and permission-aware execution policy
- Progress and verification checklists
- Optional CLI command reference and reversal guidance

### Who it is for
Claude Code users, AI coding assistants, independent developers, and teams looking for a more consistent tool-use and verification workflow.

### Requirements
No extra requirements for the instruction-only skill. The separate CLAUDE BOSS CLI requires Node.js 20+ and Claude Code.

### Compatibility
Portable Markdown instructions for agents supporting SKILL.md-style packages. Agent behavior and tool support vary. Optional CLI commands are specific to Claude Code and local terminal access.

### Known limitations
No automatic plugin installation; no guarantee of token, credit or cost reduction; no automatic Claude Code settings change; no collection or upload of private transcripts.
