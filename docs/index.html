Claude BOSS.

Choose how much effort Claude Code spends. Route bigger tasks to the right installed skills and restore your original defaults when you need to.

Install v0.3.0

Economy

Haiku and low effort for routine edits.

Balanced

Sonnet and medium effort for daily coding.

Quality

Opus and high effort for harder work.

Automatic skill routing

Type a normal Claude Code prompt. Claude BOSS recommends configured skills for design, implementation and verification. Preview the route or inspect the local inventory before applying it.

claude-boss route "Redesign dashboard and run Playwright"
claude-boss audit

Watch the work

See tool activity, observed tokens, and checklist progress in another terminal pane. The monitor makes no model calls.

claude-boss sessions
claude-boss progress "session.jsonl" --watch

Install from your terminal

Requires Node.js 20+ and Claude Code.

npm install -g https://github.com/linux-cmd/claude-boss/releases/download/v0.3.0/claude-boss-0.3.0.tgz
claude-boss setup balanced

Restart Claude Code. Run claude-boss status to inspect your setup.
