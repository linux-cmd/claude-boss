A more deliberate way to work with Claude Code.

Set sensible model defaults, surface relevant local skills, and keep track of a session's progress—all from a small CLI that fits your existing workflow.

Capabilities

Practical tools. Less friction.

A small set of focused tools that complement Claude Code instead of replacing it.

01

Model profiles

Apply Economy, Balanced or Quality defaults. Use an explicit profile for a single session or restore managed settings.

02

Local skill routing

Inspect installed skill candidates and preview suggestions. Claude Code remains responsible for actual skill invocation.

03

Session visibility

Watch observed tool activity, token counters and checklist milestones from local transcripts. No extra model calls from the monitor.

Configuration

A profile for the work at hand.

Three clear presets. No complex configuration ceremony. Project or managed policy may override user-level defaults.

Your workflow

Stay in control.

Claude BOSS does not need to become a second development platform. Configure it, inspect its local skill suggestions and monitor the work directly.

  • Preview a route before changing anything.
  • Claude Code chooses whether to invoke a suggested skill.
  • Restore managed settings when you no longer need them.
CLI reference WORKFLOW
claude-boss route "Redesign dashboard"

claude-boss sessions

claude-boss restore
Get started

Install in your terminal.

Requires Node.js 20+ and the native Claude Code CLI. Install the published package, choose a profile, then restart Claude Code.

See the v0.4.0 release for package details.

Setup WINDOWS / LINUX
npm install -g https://github.com/linux-cmd/claude-boss/releases/download/v0.4.0/claude-boss-0.4.0.tgz

claude-boss setup balanced
claude-boss status

Claude BOSS does not change billing, measure savings or guarantee that suggested skills will be invoked. Configuration behavior can vary with Claude Code version and policy.

Live terminal dashboard

Open Claude BOSS in a second pane to follow local activity and milestones without another model call.

claude-boss watch
