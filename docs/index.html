Claude BOSS.

Choose how much effort Claude Code spends. Route bigger tasks to the right installed skills and restore your original defaults when you need to.

Install v0.1.0

Economy

Haiku and low effort for routine edits.

Balanced

Sonnet and medium effort for daily coding.

Quality

Opus and high effort for harder work.

Install from your terminal

Requires Node.js 20+ and Claude Code.

npm install -g https://github.com/linux-cmd/claude-boss/releases/download/v0.1.0/claude-boss-0.1.0.tgz
claude-boss setup balanced

Restart Claude Code. Run claude-boss status to inspect your setup.

Tune it with Codex
