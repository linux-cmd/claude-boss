02 / Routing

The right skills for the task.

Claude BOSS suggests locally configured skills for ordinary prompts. Claude decides what to invoke.

Preview a suggestion or audit your local setup without modifying it.

claude-boss route "Redesign dashboard and run Playwright"
claude-boss audit

Skill availability depends on your current Claude Code configuration and permissions.

03 / Install

Up and running.

Install on Windows or Linux. Requires Node.js 20+ and the native Claude Code CLI on PATH.

npm install -g https://github.com/linux-cmd/claude-boss/releases/download/v0.3.0/claude-boss-0.3.0.tgz
claude-boss setup balanced
claude-boss status

Restart Claude Code after setup. For a one-session profile, use claude-boss run quality. To restore managed settings, use claude-boss restore.
