About the project

Built for a clearer workflow.

CLAUDE BOSS is an independent CLI focused on model profiles, local skill routing and session visibility. It is designed to complement Claude Code without adding a heavyweight interface or hosted dependency.

Creator

Built by Abhijay Panwar.

I built CLAUDE BOSS to make common Claude Code setup and workflow tasks easier to manage from a single command line.

Creator on GitHub ↗

What it does

Local tools, explicit limits.

The CLI applies profile defaults, suggests configured skills and can read local session transcripts to report observed progress. It does not change billing or guarantee model or tool behavior.

CLAUDE BOSS is not affiliated with Anthropic.
