# Changelog

## 0.5.0

- Added workspace changes, reported notes and local preview links to watch.
- Added opt-in launch-time staging for approved marketplace plugins.
- Added local token comparisons between complete transcripts.

## 0.4.0

- Added interactive terminal watch with session switching and milestone snapshots.
- Added project-aware React routing for UI implementation tasks.

## 0.3.0

- Added local session discovery and live progress monitoring.
- Shows tool outcomes, observed token counters and optional checklist completion without a model call.

## 0.2.0

- Added a local inventory of configured plugin and skill candidates.
- Added automatic routing for ordinary Claude prompts after setup and restart.
- Added audit and route preview commands.
- Added managed hook rollback and Windows/Linux CI.
- Added separate About and Changelog pages.

Routing suggests installed skills by task. It does not install marketplace plugins or observe tool execution. Usage reports are generated by Claude from its turn context.

## 0.1.0

- Added three model profiles, a routing skill, and reversible settings.
